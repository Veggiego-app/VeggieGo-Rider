# VeggieGo Rider App

Delivery Rider Android application for VeggieGo Pure Veg Food Delivery.

## Features

- Rider Login
- Accept Delivery Orders
- Live Order Status
- Pickup Confirmation
- Delivery Confirmation
- Google Maps Navigation
- Earnings Summary
- Order History
- Live Location Updates

## Technology

- Kotlin
- Jetpack Compose
- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Messaging
- Google Maps
